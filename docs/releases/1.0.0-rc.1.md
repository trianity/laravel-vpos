## Laravel VPOS v1.0.0-rc.1

The first public release candidate of `trianity/laravel-vpos` integrates Laravel 13 with the K&H eAPI v1.0 payment gateway. It supports hosted card payments, OneClick, Apple Pay, and Google Pay.

### Requirements and installation

Requires Laravel 13, PHP 8.4.27 or later in the PHP 8 series, and the OpenSSL PHP extension. Once indexed on Packagist, install the RC with:

```bash
composer require 'trianity/laravel-vpos:1.0.0-rc.1'
```

See the [integration guide](https://github.com/trianity/laravel-vpos/blob/v1.0.0-rc.1/README.md) for sandbox configuration, checkout persistence, callback verification, and status reconciliation. The host must store the verified payment ID before redirecting the payer.

### Verification and release scope

- Offline CI covers all 17 executable operations in the K&H PHP sample suite. PHP 8.4.27 and 8.5 each pass 114 tests and 342 assertions, Composer validation, Larastan, and Pint.
- Signed GET and POST Echo passed against the K&H sandbox. The POST canonical request string matched the gateway diagnostic header.
- End-to-end sandbox acceptance remains pending for hosted payments, manual close, reversal, refund, OneClick, and both wallets. Use this prerelease for integration and sandbox evaluation. Complete the [K&H acceptance runbook](https://github.com/trianity/laravel-vpos/blob/v1.0.0-rc.1/docs/acceptance-and-sandbox.md) before production rollout.
